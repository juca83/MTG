# Site publié — Chimère

`index.html` est la version mise en ligne de l'application, servie par
GitHub Pages à l'adresse **https://juca83.github.io/MTG/**

C'est une copie de `chimere/chimere_tirage.html`. Pour publier une nouvelle
version (par exemple après l'enrichissement BoardGameGeek), remplacer
`docs/index.html` par le fichier voulu, puis pousser la modification :
la mise en ligne est automatique et prend une à deux minutes.
